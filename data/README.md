# Data

## What's here

`corpus/` contains the knowledge base used by the retrieval pipeline: **synthetic** food-security reports written in the style and structure of real FEWS NET / FAO GIEWS Food Security Outlooks (IPC phase classification, regional drivers, seasonal outlook), plus three methodology notes on IPC classification, remote-sensing crop-failure early warning indicators (NDVI, rainfall anomaly, WRSI), and pastoral terms of trade.

These documents are synthetic (written for this project, not copy-pasted from copyrighted reports) but are grounded in real terminology, real regions, and real 2026 dynamics reported by FEWS NET, so they are realistic enough to exercise hybrid retrieval, reranking, and RAGAS evaluation meaningfully.

## How to populate with real data (recommended before final submission)

For a stronger report, replace/extend this corpus with real public-domain reports:

1. Go to https://fews.net, pick 8-12 country "Food Security Outlook" or "Outlook Update" reports (PDF or web page).
2. Save the text content as `.md` files under `data/corpus/` (one file per report). FEWS NET content is U.S. government-produced and generally public domain, but always check the specific report's license/citation notice before wide redistribution.
3. Optionally add FAO GIEWS country briefs (https://www.fao.org/giews) the same way.
4. Re-run `python src/build_index.py` to rebuild the BM25 + embedding indices (see README.md at repo root).

## Files

- `corpus/*.md` — the retrieval corpus (8 documents)
- `eval/questions.jsonl` (generated by you, see `docs/architecture.md`) — RAGAS evaluation question set derived from the corpus
